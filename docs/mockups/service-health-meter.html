One email when a service turns unhealthy, one when it recovers. Nothing repeats every hour, and "needs attention" items only show on the meter.

WHAT IS CHECKED, ONCE AN HOUR

Database (a one-row read), Sign-in (Supabase Auth API), File storage (both buckets present), Mux (list one asset; signing key present), Daily (account call), Email (Resend accepts the key), Support inbox (the Gmail script pings the API on every run; silent for 20 minutes turns red), Stripe (balance call once connected), Web app and Marketing site (a page load from the server), Server disk (free space; under 15% amber, under 5% red). Each probe is read-only and gets 8 seconds. The values above are a real run against the dev services; the Mux amber is right, dev has no signing key (production does).
